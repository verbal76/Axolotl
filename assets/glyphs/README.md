# Controller and keyboard prompts

Imported subset of the studio's approved glyph library (`Source.zip`, sha256
`f6c75921b9d6ab2cb2b5249f547c7b7ba19e22da9f4f3b45693cf0912f25ded0`): **"Input Prompts" by Julio Cacko**,
128 x 128 PNG, files copied unchanged with their original names.

- `xbox/`: `Source/XGamepad/Default/` (A/B/X/Y in Color for Xbox pads and White for Steam Deck / Steam
  Controller; LB, RB; `T_X_X` = Menu; `T_X_Share` = View; `T_X_L_2D` / `T_X_R_2D` = sticks)
- `ps/`: `Source/P5Gamepad/Default/` (Cross, Circle, Square, Triangle in Color; L1, R1, Options, Share,
  sticks; L1/R1 also serve the Steam Deck, whose bumpers carry those labels)
- `keys/`: `Source/Keyboard_Mouse/Dark/` (the keys the game binds)
